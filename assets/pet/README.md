# 素材目录

程序运行时需要本目录下存在以下文件：

```
assets/pet/
├── idle.webp        # 待机静态帧（透明背景）
├── laugh.wav        # 点击时的音效
├── laugh/           # 大笑序列帧（30fps，0000.webp、0001.webp…，帧数即动作时长）
├── blink/           # 眨眼帧（可选，00..04.webp；缺目录就不眨眼，不报错）
├── talk/            # 张嘴帧（可选，00..05.webp，张口由小到大；缺目录就无口型）
└── voice/           # 语音（可选，curves.json + 每句一个 wav；缺目录就没有「音频」菜单）
```

所有帧的画布尺寸必须完全一致（本工程为 560x827），否则切换瞬间角色会跳位。
`process_assets.py` 用全帧统一包围盒保证这一点；`make_blink.py`、
`make_talk.py` 直接以 `idle.webp` 为底图生成，天然对齐。

这些素材是**第三方角色（奶龙/奶娃）**，随仓库分发仅供个人学习与朋友间
玩耍，未获授权商用（见根目录 README 版权说明）。两条路：

- **直接用**：素材就在这里，`python src/main.py` 即可运行。
- **换成你自己的角色 / 把仓库变成纯代码**：按根目录 README 的「素材 SOP」
  处理你自己的视频；或 `python tools/make_placeholder.py --force` 用原创
  占位角色「蛋蛋」整套顶替本目录内容。
